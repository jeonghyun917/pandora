## PDF resource/identity contract

cross-format fidelity. Existing128MiBheap/96MiBmetaspace/32MiBdirect-memory,
child8s watchdog/parent10s/2worker permits/64KiB stdout and inherited-option refusal
remain. Stdout is drained concurrently with a bounded2-reader pool to avoid pipe
deadlock; worker ownership and cleanup remain bounded. Input hashing is under
admission with an8MiB bounded read and rechecked against the worker's actual bytes.

Position protocol: at most1000pages/8192glyphs,512KiB expanded and36KiB compressed,
canonical single gzip representation, finite positive page/box dimensions,
physical page ownership and in-page coordinates. Unknown rotation/direction,
overflow, trailing data and unsupported coordinates reject without partial proof.
No PDFBox processing runs in the serving JVM. Normal hash-only inspection still
works for PDFs exceeding the optional native-position bound.
