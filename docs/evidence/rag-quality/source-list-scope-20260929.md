## 변경 범위

- 본문에 실제로 존재하는 청크 제목 뒤의 연속 번호 목록에만 범위를 복원한다.
- 제목 메타데이터만 있는 경우, 번호가 재시작하는 경우, 다른 제목/문단이 이어지는 경우에는 기존 분해 방식으로 돌아간다.
- 예외나 복합 절을 여러 범위 주장으로 배분하지 않는다.
- 복원한 `제목: 항목` 근거는 원문 형태의 답변 보정에만 사용한다. 제목 단어의 유사도로 원문에 없는 항목을 지지하지 않도록 정확 일치 검사를 추가한다.
- 검색 근거와 답변 보정이 같은 원문 목록 해석을 사용한다. 평가 정답이나 질문별 임계값은 변경하지 않는다.
